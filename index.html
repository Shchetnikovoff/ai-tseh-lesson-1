Харнес в разрезе

Папка, агент, модель, инструменты

Харнес это вся обвязка вокруг модели. Он переносится с одного агента на другого, поэтому разбираем его один раз и запоминаем на весь поток.

Папка-окружение

Правила проекта, файлы и результаты. Тоже часть харнеса.

Агент

Кто читает папку, задаёт вопросы и выполняет шаги.

Модель

Кто думает и отвечает. Меняется под задачу.

Инструменты

Что агент умеет подключать: файлы, поиск, сервисы.

  • Кодекс и Claude Code это харнесы, а не модели.
  • Один и тот же порядок работы переезжает между ними почти без потерь.
Что такое кодинг-агент

Чат отвечает, агент делает

Разница не в уме, а в руках. Чат выдаёт текст в окне. Агент работает в папке и оставляет там файл, который можно открыть.

Обычный чат

Задали вопрос, получили ответ. Вашу папку он не видит.

Кодинг-агент

Читает файлы, правит их, запускает команды, показывает шаги.

  • Агент может подготовить и объяснить, важное действие подтверждает человек.
  • Правило курса: слово «готово» от агента доказательством не считается, результат проверяем руками.
Почему сейчас Claude

Два входа и два усилителя

Claude это один ассистент: обычный чат и агент в папке, в браузере, на телефоне и на компьютере. 16 сентября 2026 Anthropic слила Cowork, Claude Design и обычный чат в один Claude, поэтому режим больше не выбирают заранее: вы пишете задачу, а Claude сам решает, ответить быстро или взяться за работу.

Вход: приложение Claude

Веб, десктоп, телефон. От разового вопроса до многошаговой задачи с файлами.

Вход: Claude Code

Тот же Claude, но с руками: работает в папке на вашем компьютере.

Усилитель: проекты

Постоянный контекст: инструкции и файлы действуют в каждом чате проекта.

Усилитель: навыки

Ваша процедура, которую Claude подключает сам, когда задача совпала.

  • Что такое Claude: один ассистент в нескольких входах, от разового вопроса до работы в вашей папке.
  • Почему сейчас Claude: после слияния 16.09.2026 входов два, усилителей два, отдельный режим Cowork больше не выбирают.

Переезд из Кодекса

Перенос правил | Один файл AGENTS.md

Правила, наработанные в Кодексе, переезжают в Claude без переписывания. Источник один: AGENTS.md. С версии 2.1.277 Claude Code читает его сам, если рядом нет CLAUDE.md.

AGENTS.md   все правила проекта, один источник
            Кодекс их читал, Claude Code читает с версии 2.1.277
CLAUDE.md   не обязателен: одна строка @AGENTS.md, если нужен импорт
  • Переносим свои правила в AGENTS.md один раз: текст уже ваш, переписывать не нужно.
  • Claude Code с версии 2.1.277 читает AGENTS.md сам, CLAUDE.md не обязателен.
  • Хотите списки памяти и хуки как раньше: оставьте в CLAUDE.md одну строку @AGENTS.md, это ничего не ломает.
  • Второй файл правил не заводим: два текста расходятся. Оба агента на одних файлах одновременно не запускаем.

Персонализация

Что переносим из Кодекса

У группы уже есть папка-окружение и привычки из Кодекса. Не начинаем с чистого листа, а переносим то, что доказало себя.

  • Роль и тон: кто вы, что продаёте, как называете вещи своими словами.
  • Правила работы: сначала вопросы и план, потом действие.
  • Запреты: не выдумывать цены, не обещать сроки, не трогать лишние файлы.
  • Порядок проверки: расчёт кодом, контрольная сумма, сверка одной цифры с исходником.
  • Повторяющиеся процедуры выносим из головы в навык.
  • Мастер-инструкция и superpowers: сборщики, знакомые по Кодексу. В Claude запускаем их так же, порядок работы не меняем.
  • Курс переезжает в Claude, поэтому переносим всё подряд, а не начинаем с чистого листа.
AGENTS.md и скиллы

Одна правда для Claude

Правила проекта живут в одном файле AGENTS.md: Claude Code с версии 2.1.277 берёт его сам, если рядом нет CLAUDE.md. Процедуры живут в навыках, у Кодекса и Claude папки разные, формат общий.

проект/
  AGENTS.md          все правила проекта, один источник
  CLAUDE.md          не обязателен: одна строка @AGENTS.md по желанию
  .agents/skills/    навыки
  .claude/skills/    ссылка или копия папки навыков
  .codex/  .claude/  настройки и MCP: у каждого свои
  • Формат навыков один, это открытый стандарт Agent Skills.
  • Навык «франкенштейн» из прошлого потока остаётся с группой: те же навыки подключаются в Claude, формат общий.
  • Папки навыков разные, поэтому общий набор удобно держать в одной и ссылаться на неё.
  • Хотите видеть правила в списках памяти и на хуках: оставьте в CLAUDE.md одну строку @AGENTS.md.
  • После настройки одного источника команду импорта не запускаем, она делает копию и правила расходятся.
Настройка, часть 1

Тумблеры, инструкции, режим подтверждений

Делаем медленно и вслух переводим каждый экран. Показываю я на ученическом аккаунте, свежем как у вас, повторяете вы на своём. Первая часть это то, без чего остальное просто не заработает.

  1. Открыть Settings и найти раздел Capabilities.
  2. Проверить глазами тумблер Code execution and file creation. Без него нет ни файлов, ни навыков, ни артефактов.
  3. Заполнить Instructions for Claude: роль, тон, язык, запреты. Коротко, без простыни.
  4. Выбрать режим подтверждений. Первую неделю живём в ручном режиме.
  5. Проверить экран Usage и понять, где смотреть остаток лимита.
Настройка, часть 2

Проекты, навыки и папка на компьютере

Вторая часть про усилители. Делаю я на ученическом аккаунте, повторяете вы. Проект даёт постоянный контекст, навык даёт процедуру, папка на компьютере даёт доступ к вашим файлам.

  1. Создать проект и наполнить его: инструкция, шаблоны, рабочие документы.
  2. Проверить в чате проекта, какие инструкции и файлы Claude видит на самом деле.
  3. Загрузить или собрать разговором один навык под повторяющуюся задачу.
  4. В приложении на компьютере подключить отдельную рабочую папку, а не рабочий стол целиком.
  5. Ещё раз подтвердить ручной режим подтверждений перед работой с файлами.
Кульминация

Claude разбирает мои документы

Самая важная часть урока: копия безопасной папки, ручной режим, разбор под контролем человека.

Работай с папкой «Документы-копия». Файлы не меняй и не удаляй, только чтение.

Задача: собери реестр по этим файлам и покажи риски. Порядок:
1. Из каждого файла вытащи: контрагент, номер и дата, предмет, сумма, сроки, штрафы, ответственный.
2. Собери файл Excel в этой же папке: один файл это одна строка, рядом имя исходного файла.
3. Лист «Внимание»: что истекает в ближайшие 60 дней и где условия жёстче обычного.
4. Лист «Не разобрал»: непрочитанные файлы и поля, которых нет.
Правила: пустое поле оставляй пустым, не додумывай, непонятное пиши «уточнить», суммы не пересчитывай.
В конце сообщи три строки: сколько файлов обработал, сколько строк в реестре, сколько в «Внимание».
Сначала покажи план текстом и дождись моего «ок».
  • Результат: файл Excel с реестром, лист внимания и список непрочитанного.
  • Проверка: пять случайных строк сверяем с оригиналами руками.
  • Gmail и показ: почту подключаем в Connectors, показ идёт на ученическом аккаунте.
  • Безопасность: только копия, ничего не удаляем, не отправляем и не храним личного.
Проверка переезда

Перенос завершён

Переезд из Кодекса в Claude закончен. Проверяем глазами, что всё доехало: правила, навыки, привычный порядок работы.

  1. Открыть AGENTS.md в Claude и убедиться, что правила доехали.
  2. Позвать навык «франкенштейн» и проверить, что он откликается как раньше.
  3. Сверить порядок работы: вопросы, план, действие, проверка руками.
  4. Прогнать одну маленькую задачу глазами от плана до файла.
  • Один файл правил: AGENTS.md, Claude Code читает его сам, CLAUDE.md не обязателен.
  • Проверка на своих руках: Claude открывает AGENTS.md и строит первую задачу на своих правилах.
  • Второй файл правил не заводим, важное действие подтверждает человек.
План недели

Один вечер на настройку и две задачи

Не пытаемся переделать весь рабочий процесс за неделю. Двигаемся маленькими проверяемыми шагами.

  1. Вечер на настройку: тумблеры, инструкции, режим подтверждений, проект, папка.
  2. Первая задача в чате: то, что вы и так делаете руками каждую неделю.
  3. Вторая задача в Claude Code или в приложении на копии папки.
  4. Третий раз объяснили одно и то же, значит пора складывать это в проект или в навык.
